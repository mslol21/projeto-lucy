# Depoimento 04 — vídeo

Esta pasta está pronta para receber **um arquivo MP4**.

1. Renomeie o arquivo originalmente chamado `358128.mp4` para **`video-01.mp4`**.
2. Faça upload do arquivo nesta pasta pelo GitHub, sem alterar o código.
3. Confirme o commit e acompanhe o deploy na Vercel.

Após a publicação, o site identifica automaticamente o arquivo e exibe o player com controles. Até lá, mostra uma mensagem discreta de espera.

Vídeo recomendado: MP4 H.264/AAC. Otimize o tamanho do arquivo para melhor reprodução.

**Atenção:** este vídeo fica publicamente acessível quando publicado em `public`. Use apenas materiais autorizados. O relato de alterações vasculares e peso não será publicado automaticamente: essas informações exigem revisão clínica e contextualização para não sugerir causalidade.
