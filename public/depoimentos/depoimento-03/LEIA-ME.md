# Depoimento 03 — vídeos

Esta pasta está pronta para receber **dois arquivos MP4**.

1. Renomeie o arquivo originalmente chamado `358078.mp4` para **`video-01.mp4`**.
2. Renomeie o arquivo originalmente chamado `358085.mp4` para **`video-02.mp4`**.
3. Faça upload dos dois arquivos nesta pasta pelo GitHub, sem alterar o código.
4. Confirme o commit. A Vercel publicará automaticamente os vídeos depois do deploy.

O site identifica os arquivos MP4 disponíveis automaticamente e exibe controles de reprodução. Arquivos ausentes ficam com uma mensagem de espera; isso evita vídeo quebrado.

Vídeos devem ser H.264/AAC em MP4 para maior compatibilidade. Recomendamos arquivos otimizados, idealmente abaixo de 50 MB. Upload de vídeo grande pelo GitHub pode exigir outra hospedagem.

**Atenção:** esta pasta `public` é publicamente acessível. Faça upload somente de materiais autorizados para exibição pública. Legendas e transcrição em português devem ser providenciadas quando possível para acessibilidade.
